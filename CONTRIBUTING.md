# Contributing to OpenGalaxy

Thanks for your interest in contributing to OpenGalaxy!

We welcome all contributions, whether it's a bug fix, a new feature, or improvements to documentation.

---

## 🔧 How to Contribute

1. **Fork** the repository.
2. **Clone** your fork locally:

   ```bash
   git clone https://github.com/your-username/opengalaxy.git
   ```

3. **Create** a new branch:

    ```bash
    git checkout -b feature/your-feature-name
    ```

    or

    ```bash
    git checkout -b fix/your-fix-name
    ```

4. **Make your changes**, following the existing coding style.
5. **Commit** with a clear message:

    ```bash
    git commit -m "Add: new feature to support XYZ"
    ```

6. **Push** to your fork:

    ```bash
    git push origin your-branch-name
    ```

7. **Open a Pull Request*** targeting the `main` branch.

## 🧪 Code Style & Testing

- Keep your changes focused.
- Use descriptive commit messages.
- Add or update tests where appropriate.

## 🐛 Reporting Bugs or Requesting Features

Before you start work, it helps to [open an issue](https://github.com/alfieatkinson/opengalaxy/issues/new/choose) to discuss what you plan to do.

Please use the relevant issue templates:

- Feature Request
- Bug Report

## 🙌 Questions?

Feel free to [open a discussion](https://github.com/alfieatkinson/opengalaxy/discussions) if you're unsure about anything.

Thanks again!
